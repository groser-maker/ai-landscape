  • Token Optimization Best Practices
    • Cost Background Canvas – Where cost comes from
      • Don't include files, just paste links
      • Be careful spawning subagents
      • Cache is only 5 minutes… after that the whole context has to be re-read
    • Actionable Tips Canvas
      • Has a ready-made CLAUDE.md block with instant savings
    • Start fresh: Chat history is resent every turn, so long threads get heavier over time. Start a new thread when topics change or the AI starts to drift.
    • Hit Stop: If a response is long or off-track, stop it and re-prompt with a tighter ask.
    • Reuse what works: Save effective prompts, skills, agents, and workflows instead of rebuilding them. Turn recurring tasks into a Gem or Slackbot Skill, and put shared rules in a file like AGENTS.md or CLAUDE.md.
    • Curate your context: Reduce unnecessary context and provide only the relevant files, logs, or requirements. A few exact files beat a whole directory.
    • Document as you go: Ask the model to summarize its findings so you can pick the work back up later without starting over.
    • Turn off what you're not using: Every active tool integration (like an MCP server) adds overhead to the prompt. Keep only what you need.
